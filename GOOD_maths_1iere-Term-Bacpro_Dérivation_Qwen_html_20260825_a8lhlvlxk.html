📐 Règles — couleur = parenthèses

Bac Pro
(u + v)′ = u′ + v′
(k·u)′ = k·u′
(xn)′ = n·xn−1

Lycée général
(u·v)′ = u′v + uv′
(u/v)′ = (u′v − uv′)/v²
(un)′ = n·u′·un−1

⌨️ Rôle des touches

AC : efface l'écran
f(x) : tire une nouvelle fonction et l'affiche
f′(x) : affiche la dérivée (Dériver)
SOLVE : résoudre f′(x) = 0 (numérique)
SIGNE : tableau de signe de f′
VAR : variations de f + extremums
EXE : déroule toute l'étude

🧾 Méthode (sans discriminant)

1. Dériver f(x)
2. Résoudre f′(x) = 0
3. Signe de f′ entre les solutions
4. Tableau de signe → variations
5. Extremums là où f′ change de signe

➕ Signe → variation

f′ > 0 → f croissante • f′ < 0 → f décroissante
+ → − : maximum • − → + : minimum
