Synthèse Organique et Analyse par Chromatographie (CCM)

Contrôles CCM

Objectif TP : Analyser la pureté d'un ester de synthèse (Salicylate de méthyle). Déposer sur la plaque :
A : Réactif 1 (Acide salicylique)
B : Réactif 2 (Méthanol / Alcool)
C : Ester synthétisé (Produit de synthèse)
Prêt pour le dépôt.
Lampe UV Éteinte
A
B
C

Mesures et Calculs

Mesurez les rapports frontaux $R_f = \frac{d}{D}$ où :
- $D$ = distance de migration du solvant (du dépôt à la ligne de front) = 6,0 cm
- $d$ = distance de migration de la tache.

Tache Distance $d$ (cm) Rapport frontal $R_f$
A (Acide Salicylique) - -
B (Méthanol) - -
C (Ester de synthèse) - -
Analyse de pureté : Si le dépôt C montre une seule tache identique en hauteur à un produit attendu, il est pur. S'il montre une tache résiduelle de A ou B, la synthèse est incomplète.
